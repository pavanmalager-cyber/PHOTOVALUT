# Persistent Image Gallery\n\nPublic full-screen image gallery plus private admin page. The title and image records are stored in PostgreSQL; image files are stored in Cloudinary.\n\n## Deployment\n1. Create a Cloudinary account at https://cloudinary.com and copy Cloud Name, API Key, API Secret.\n2. Deploy this repository as a Render Python Web Service: build command `pip install -r requirements.txt`, start command `gunicorn app:app`.\n3. Add Render environment variables: `SECRET_KEY` (long random secret), `DATABASE_URL` (PostgreSQL internal connection string), `CLOUDINARY_CLOUD_NAME`, `CLOUDINARY_API_KEY`, `CLOUDINARY_API_SECRET`.\n4. Open `/manage-7f3a` on your live site and create a strong password immediately. The first-time setup is only available before the password exists.\n5. Public page is `/`; admin page is `/manage-7f3a`. The admin URL is unlinked from the public site, but password protection is the real security boundary.\n\nDo not commit secrets. Render's ephemeral filesystem is not suitable for persistent SQLite; use PostgreSQL. Cloudinary credentials are required for image uploads. Review costs before creating paid resources.\n
